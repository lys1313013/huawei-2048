# 2048 轻量练习场

一句话简介：原生网页技术打造的 2048 练习游戏，支持键盘、按钮与触屏操作。

## 使用

直接在现代浏览器中打开 `index.html` 即可开始，无需安装依赖、启动服务器或登录账号。使用方向键或 WASD、棋盘下方方向按钮，也可以在棋盘上滑动。每次有效移动后生成一个新数字；可以重新开始或撤销最近一次有效移动。达到 2048 后仍可继续游戏。

## 离线与隐私

游戏逻辑在浏览器本地运行，不需要连接业务后端，也不提交棋盘或操作记录。实现使用浏览器 `localStorage` 保存最高分（键名 `pocket2048-best`）；清除该站点的本地存储会清除这项记录。若从远程托管页面访问，浏览器仍会向托管服务请求页面资源；“离线运行”指可将文件下载到本地后直接打开，不代表远程托管访问不产生网络请求。

## 验证

在包含源码和脚本的目录运行：

```bash
node verify-2048.js
```

脚本从 HTML 的纯函数标记区提取 `slideLine`、`moveBoard` 和 `isGameOver`，使用 Node.js VM 验证合并与计分、单块每步只合并一次、无效移动保持棋盘且不触发生成新块、四方向映射及游戏结束判断。它检查无效移动提前返回早于 `spawn()` 的源码顺序。

这不是浏览器端到端测试。脚本没有模拟键盘、按钮、触屏、DOM 渲染、撤销交互或 `localStorage`；这些行为可通过浏览器手工检查。脚本通过不等于已完成云端部署、线上性能测试或用户规模验证。
